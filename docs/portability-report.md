# 通用安装、飞书更新与刷新验收

日期：2026-10-15。遵守 [项目最高准则](../AGENTS.md#最高准则通用化与可复现)。验收环境为 macOS 上的独立模拟用户，覆盖用户目录、安装位置、工具位置和 Python 版本差异。

## 改动

- `scripts/build-app.sh` 寻找受支持的 Python；`scripts/install.py` 生成当前用户的应用和命令行入口，正确处理路径中的空格、引号和特殊字符，不含维护者的固定目录。
- `skill_pilot/environment.py` 统一查找当前用户的工具，覆盖终端搜索路径、常见用户目录、Homebrew 和不同版本的 nvm 安装目录。安装入口记住实际工具位置，桌面启动无需加载终端配置。
- 飞书检查使用当前用户的工具和主目录；新版仍在独立临时目录安装，再交给原有的备份、更新和撤销流程。两类安装配置使用不同位置，避免原先的配置冲突。
- 刷新会先核对命令入口和后台是否能加载，再等待当前任务完成并切换；保留地址、进程、会话和已检查结果。新版入口或后台未准备完整时，原看板继续运行，修复后可刷新重试。
- [README](../README.md) 提供公开获取、安装、首次使用及更新步骤。普通同目录更新取得文件后刷新即可；旧版首次升级需要重建安装入口并正常重开一次。

## 已通过的检查

| 情况 | 验证结果 |
| --- | --- |
| 新用户与不同安装位置 | 使用全新模拟 home 和独立源码副本，安装实际应用与命令行，读取到该用户目录 |
| 空格、引号和特殊字符 | 项目路径含空格、单引号和字面量 `$()`，安装及启动正常，没有被当成命令执行 |
| 移动项目位置 | 移动后重新运行安装，入口使用新位置并可正常启动 |
| 桌面启动 | 只保留系统搜索路径，从实际生成的应用入口启动，完成首次整理并打开该用户的看板 |
| Python 版本 | Python 3.11.15 全量回归；Python 3.12.14 运行安装与刷新相关的 15 项检查；不支持的显式 Python 入口会在写文件前报错 |
| 飞书与 Node 位置 | 优先使用当前用户的飞书入口，也能识别其他前缀的工具与不同版本目录中的 Node |
| 缺少工具 | 找不到飞书入口或缺少 Node/npm 时，明确报告安装要求，技能保持原样 |
| 飞书官方实际更新 | 下载官方技能和飞书工具 1.0.98，执行实际工具确认版本；完成技能更新后撤销，工具、技能入口、基准和登记表的指纹恢复一致 |
| 刷新应用程序 | 从已安装入口启动，修改临时源码并请求刷新；地址和进程保持，后台实际加载新版，技能库不变 |
| 忙碌、残缺新版与重试 | 当前任务先完成；后台或命令入口未准备完整时保留旧看板；修复后可重试；重复刷新、备用连接和仅外观变化均有回归覆盖 |
| 批量更新部分失败 | 独立技能继续处理，飞书整组处理，失败项列明原因；成功项可撤销，恢复失败时停止后续写入 |

自动回归位于 `tests/test_portability.py`、`tests/test_runtime.py`、`tests/test_update_batch.py` 和现有测试中。243 项全量测试通过（77.978 秒），Python 3.12 的 15 项专项检查通过；页面脚本、安装脚本和改动格式检查通过。后台到期退出的测试改为等待任务线程完成，避免在后台按预期退出后继续请求；本机 HTTP 测试请求设有超时。飞书官方下载安装属于额外的联网实测，不依赖维护者的账号、设置或真实技能内容。
