# 交接：安装技能少点几下（前端）

2026-10-14，Claude 写给 DSH。先读仓库根目录 `AGENTS.md`、`DESIGN.md`（界面规则）、`PRODUCT.md`，再读本文件。背景和后端部分见 `docs/handoff-install-flow.md`（Codex 同时在做，接口字段不变，你不用等它）。

## 用户的问题

用户原话：粘贴一个链接进去，页面要读取半天；然后给技能打钩、点安装，弹出的窗口上还要再点一次安装；装完还要刷新一次，刷新之后又要调用 AI 去整理中文名和标签。“安装一个技能搞得太麻烦了。”

目标：**粘贴链接 → 点一次“安装” → 关窗、技能已经出现在列表里，中文名在后台自己补上，不用刷新。**

## 分工

- **你（DSH）**：只改 `skill_pilot/web/static/app.js`、`index.html`，需要时改 `app.css`。
- 不要改任何 Python 文件、测试和 `docs/`。

## 现在的代码

`app.js` 里“安装技能：对话框”一段（`openInstall`、`#install-inspect`、`#install-apply`、`showIncomingConflicts`），`index.html` 里 `#install-dialog`。中文名整理在“设置与中文名”一段：`startLabels(mode)` 会先查后台进度、没在跑才发起，然后轮询并在任务条显示进度，结束时 `refreshTable(true)`。现在只在打开页面时自动整理一次（`labelsAutoAttempted`），所以装完新技能不刷新就不会起中文名。

## 要改的

1. **粘贴就读取，去掉“读取”按钮。** 在链接框里粘贴、按回车，或输入停下约 0.6 秒且内容像完整的 `https://github.com/...` 链接时自动读取。同一个链接读过就不再重复读；读取中换了链接，旧的结果回来要丢掉（用一个递增序号判断）。读取时状态行写“正在读取…”；出错时把后台给的中文原因显示出来，再给一个“重试”小按钮。
2. **找到的技能默认全勾。** 每个技能一行勾选框，默认勾上。同名冲突（`conflicts` 里有它）：`same_content` 为真的显示“已经装过”、不能勾；内容不同的默认不勾，保留现在“已有同名技能”的提示。全都装过时状态行写“这些技能都已经装过了”。读完后把焦点放到“安装”按钮上。
3. **给哪些 agent：默认勾上技能页当前在看的那个**（`currentAgent()`），用户可以多勾或取消。小提示 ⓘ 改成“默认给你正在看的 agent；装完也可以在技能页里调”。
4. **只点一次安装。** 按钮文字“安装”，至少勾了一个技能才能点。点了直接装，**不再弹确认框**（安装可以撤销，和技能页“加技能直接应用、事后可撤销”一致）。照旧走 `runWrite`，忙碌文字“正在安装…”。
5. **完成提示**带“撤销”（照旧 `undoOperation`）：
   - 一个技能：`装好了 lemo-opuscar，给了 Codex、Claude`
   - 多个：`装好了 3 个技能，给了 Codex`
   - 没选 agent：后半句换成 `，还没给 agent 用`
   agent 名用 `agentName()`，技能用原名（这时还没有中文名）。
6. **装完不用刷新。** 关窗、`refreshEverything()`（照旧），然后如果 `state.table.llm_configured` 为真就调用 `startLabels('missing')`。如果整理已经在跑，它会接着显示进度；后台会把刚装的技能排到下一批最前面。整理结束时 `startLabels` 原有逻辑会刷新列表，中文名自己出现。
7. **保留**：同名内容不同时的对比区（`showIncomingConflicts`），以及“收进仓库”遇到冲突时打开这个对话框看对比的用法（`openInstall()` 后直接 `showIncomingConflicts`，没有链接）——这个用法下不要触发读取，也不要因为默认勾选出问题。只读模式下照旧不能安装。
8. 用词照 `DESIGN.md` 和 `AGENTS.md`：中文大白话，说 agent 不说“助手”，不出现仓库、克隆、git 这类词。“只读取文件，不运行里面的程序”那一行保留。
