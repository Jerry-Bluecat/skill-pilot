## 可读 / 可写范围

- **可写**：`~/Developer/skill-pilot/`（不要 commit、push）、系统临时目录、`~/Applications/Skill Pilot.app`、`~/.local/bin/skill-pilot`。
- **只读**：四个技能根、`~/.skill-pilot/`、`~/.codex/config.toml`、`~/.agents/.skill-lock.json`、各 agent 会话记录。开发和验收中凡是对真实 home 运行本工具，一律带 `SKILL_PILOT_READ_ONLY=1`。
- **禁止**：对真实 home 执行任何分配、更新、清理、收编、改来源、撤销；让 skill-pilot 技能在真实 home 自动入库（这一步留给用户第一次双击）；运行 `lark-cli update`、`npx skills`；执行技能里的脚本。
- 网络：只读请求。

## 验收方式

- 双击 `Skill Pilot.app`（可用 `open -a`）真实启动一次：看板打开、页面能读到真实 home 的数据；**不点任何写按钮**；关页面 30 秒内进程退出；连续双击两次只有一个进程。为了不在真实 home 触发首次自动入库，这次实测用 `SKILL_PILOT_READ_ONLY=1` 或等效方式启动，并在报告里说明用户第一次双击时会发生什么。
- 模拟 home 中：首次启动自动入库并分配 skill-pilot 技能；四个 agent 的模拟根目录都有它；撤销后消失。
- 模拟 home 中走一遍：清理（默认全选、取消一个、执行、撤销）、检查更新（本机改过的默认“用上游的”）、勾选表给 Claude 勾 grill-me（grilling 跟上）、手动加删一条依赖。全程不调用 AI。
- `SKILL_PILOT_READ_ONLY=1` 下所有写操作被拒绝；不设置时真实 home 写操作有确认和备份（用模拟 home 验证逻辑）。
- 代码行数对比（前后各一次，命令同上），以及删除清单。
- 所有单测通过。主控会对比真实 home 的四个技能根、`~/.skill-pilot/`、Codex 配置和来源记录的指纹，任何改动都算越界。
